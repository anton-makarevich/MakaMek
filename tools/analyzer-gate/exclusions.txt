# Analyzer-gate allowlist (issue #1714).

# One `path:RULE[:symbol]` per line. A finding on that file with that rule is reported as
# "excluded" instead of failing the gate. The optional `symbol` is the declaration name the
# analyzer quotes in its message (for example 'ProcessCommand'): when present, only that
# declaration is excluded, so an entry cannot blanket every finding of the rule in the file.
# Everything else must be fixed or refactored.
#
# Rules for adding an entry:
#   * it must be a pre-existing finding on a type whose public contract cannot change, and
#   * the comment must name the measured value and why it cannot be reduced here.
#
# An entry whose file is part of the diff but matches no finding fails the gate, so remove
# entries once the debt is paid.
# Do NOT use this file for new debt, and never add #pragma warning disable / [SuppressMessage].
#
